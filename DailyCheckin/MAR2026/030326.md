### Python Decorator

Inner function = function inside function \

Decorator = function that takes another function and returns a modified version\

Decorators are built using inner functions\

Used for logging, timing, authentication, caching, validation, etc.\

in DA, decorators are useful for:
- Performance monitoring
- Logging
- Validation
- Error handling
- Caching
- Reusable pipeline behavior
